# Dữ liệu Lab02 — House Prices (Kaggle)

Tải từ cuộc thi: https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques
(tab Data → Download All, cần đăng nhập và chấp nhận luật thi), giải nén 4 file vào đây:

- `train.csv` (1460 dòng, có nhãn `SalePrice`)
- `test.csv` (1459 dòng, cần dự báo)
- `data_description.txt` (mô tả biến)
- `sample_submission.csv` (mẫu nộp bài)

File CSV không commit lên git (xem `.gitignore`).
